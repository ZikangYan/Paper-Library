- 数据来源：[ICML 2026 Virtual Site](https://icml.cc/virtual/2026/papers.html)
- 收录范围：去重后的主会论文
- 论文总数：**6,343**
- 形式：**159** 篇 Oral + Poster，**6,184** 篇 Poster
- 决定：**536** 篇 Spotlight，**5,807** 篇 Regular

## 使用说明

在 Excel 的 `Paper List` 工作表中，可按 `Category`、`Decision` 或 `Presentation` 筛选。每条记录包含论文标题、作者、ICML 页面和 OpenReview 链接；`PDF` 列在源数据中暂未提供链接。

| 字段 | 说明 |
| --- | --- |
| `ICML ID` | ICML 虚拟会场的论文编号 |
| `OpenReview ID` | OpenReview 论文编号 |
| `Decision` | `Regular` 或 `Spotlight` |
| `Presentation` | `Poster` 或 `Oral + Poster` |
| `Category` | 下列研究方向之一 |
| `ICML Page` / `OpenReview` | 原始论文页面链接 |
