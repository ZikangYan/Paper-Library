# AAAI 2026 Paper Library

AAAI 2026 论文主题索引。完整可筛选数据见 [AAAI_2026_paper_list.xlsx](./AAAI_2026_paper_list.xlsx)。

## 数据概览

- 主题图谱论文：**4,149** 篇
- 细分主题：**104** 个
- 代表论文：**520** 篇（每个细分主题 5 篇）
- 官方论文集分册：**48** 个

## 工作簿说明

| 工作表 | 内容 | 使用建议 |
| --- | --- | --- |
| `Overview` | 数据范围、来源、宏观主题统计和热门主题 | 快速了解整体分布 |
| `Fine Topics` | 104 个细分主题、关键词及代表论文 | 按研究方向定位论文 |
| `Representative Papers` | 每个细分主题的 5 篇代表论文 | 快速浏览主题代表作 |
| `Official Tracks` | AAAI 官方论文集分册结构 | 按官方分册查阅 |
| `README` | 数据来源与使用限制 | 阅读前先了解数据范围 |

## 使用方式

1. 在 `Fine Topics` 中按 `Macro Topic`、主题或关键词筛选。
2. 通过 `Topic Page` 打开对应主题页，进一步浏览该主题的全部论文。
3. 需要规范引文时，请以 [DBLP AAAI 2026 TOC](https://dblp.org/db/conf/aaai/aaai2026.html) 或 [AAAI 官方论文集](https://aaai.org/proceeding/aaai-40-2026/) 为准。

## 数据说明

主题图谱的标签用于导航，并非 AAAI 官方赛道名称；`Representative Papers` 仅包含每个主题的代表标题，不是完整的 4,149 篇论文标题列表。
